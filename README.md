## whoami

```console
$ whoami --verbose

  role      Web application penetration tester
  focus     Broken access control · injection · auth flaws · SSRF
            API security · client-side attacks · recon automation
  method    Map the surface first. Chain the small bugs.
            Prove impact, then write it down so it can be fixed.
  rule      Every test runs with explicit written authorization.
```

I spend most of my time on the parts of an application that other people skip: the request nobody reads, the endpoint that never made it into the docs, the third-party script quietly executing on a checkout page. When a tool I need does not exist, I build it.
