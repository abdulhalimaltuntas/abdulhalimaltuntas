# Profile artwork

The profile uses self-contained animated SVGs. `src/` contains the editable artwork;
the matching files in this directory contain vector outlines for **Space Grotesk**
and **JetBrains Mono**, so visitors do not need those fonts installed.

To rebuild the artwork, install Python's `fonttools` package and supply local TTF files:

```bash
python3 scripts/outline_svg.py \
  --display-font /path/to/SpaceGrotesk.ttf \
  --mono-font /path/to/JetBrainsMono-Regular.ttf
```

Run the command from the repository root. Edit `src/*.svg`, then regenerate the
matching output files. Text nodes use explicit font attributes and one line each;
use separate `<text>` elements instead of `<tspan>` or `<textPath>`.

Font sources: [Space Grotesk](https://github.com/floriankarsten/space-grotesk),
[JetBrains Mono](https://github.com/JetBrains/JetBrainsMono).

Recognizable tool marks in the toolkit artwork come from
[Simple Icons](https://github.com/simple-icons/simple-icons). The radar and atom
illustrations are custom artwork.

Desktop and mobile layouts have separate SVGs, with `.tr.svg` variants for Turkish.
CSS animations respect `prefers-reduced-motion`; the static artwork remains complete.
There are no scripts, embedded web pages, remote fonts, or image-service dependencies
in these panels. GitHub contribution graphics are generated by the existing workflows.
